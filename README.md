# Календарь затмений и ретроградного Меркурия на 2027 год

[Скачать календарь для импорта](2027.ics). Файл содержит пять максимумов затмений и шесть границ трёх периодов ретроградности Меркурия. Время в файле хранится в UTC, приложение календаря покажет его в вашем часовом поясе.

| Событие | Дата и время по Москве |
|---|---|
| Кольцеобразное солнечное затмение | 6 февраля, 19:00 |
| Полутеневое лунное затмение | 21 февраля, 02:13 |
| Полутеневое лунное затмение, касание полутени | 18 июля, 19:03 |
| Полное солнечное затмение | 2 августа, 13:07 |
| Полутеневое лунное затмение | 17 августа, 10:14 |

| Ретроградный Меркурий | Начало, МСК | Конец, МСК |
|---|---|---|
| Первый период | 9 февраля, 20:36 | 3 марта, 15:32 |
| Второй период | 10 июня, 21:15 | 4 июля, 22:39 |
| Третий период | 7 октября, 17:37 | 28 октября, 17:11 |

Февральское лунное затмение начинается в таблице с московской даты максимума. В UTC максимум ещё приходится на 20 февраля. Местное время максимума и видимость из конкретного города проверяйте отдельно.

Создайте отдельный календарь и импортируйте в него файл. Так будет легко заменить набор дат при обновлении. Источники: [затмения и видимость](https://aistre.ru/journal/zatmeniya-2027?utm_source=github&utm_medium=referral&utm_campaign=natalcard_readme_pilot&utm_content=astrokalendar-sobytiy), [периоды Меркурия](https://aistre.ru/journal/retrogradnyy-merkuriy-2027), [каталог NASA](https://eclipse.gsfc.nasa.gov/OH/OH2027.html).
